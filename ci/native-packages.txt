# Packages the CI builds natively for riscv32, one aports directory per line,
# built from top to bottom. A package's build dependencies must come before
# it, because abuild installs them from the packages built so far.
# bootstrap.sh's own list (step 9) and mdev-conf are cross-built before these.
#
# To add a package: add its line after its dependencies; if its APKBUILD
# needs an edit, add the patch to patches/ in the same push.
#
# A second word on a line is an option for ci/native-build.sh:
#   rebuild-if-cross  build it again natively if the package in the
#                     repository is bootstrap.sh's cross build (openssl)
